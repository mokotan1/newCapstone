필요한 기능
1. 목마 하나하나 마다 드레그 되도록
-> 드레그 된 목마들은 육망성의 숫자 위로
가면 그 숫자에 고정되도록 알맞은 숫자에
가지 않아도 괜찮음
-> 목마가 알맞은 숫자에 간다면 flag =  true
[EX] 흰색 목마가 1에 간다면 그 숫자에 고정

<!-- page: 11 -->
필요한 기능
 -구체적인 개발
-> 각 번호 + 앞에 [EX] 빨간색 테두리에
투명한 오브젝트 생성 + 콜라이더
목마 오브젝트의 콜라이더와 투명한
오브젝트의 콜라이더가 충돌하면 목마
오브젝트가 투명한 오브젝트의 피봇값으로
이동
-> 투명 오브젝트 피봇 == center
-> 투명 오브젝트는 squre에 알파값 == 0

필요한 기능
 -나머지 인벤토리에 들어가는 아이템 개발
-> 인벤토리로 들어온 아이템도 마찬가지로
인벤토리에서 드레그
-> 이후 투명한 오브젝트와 마우스가
충돌하면 투명한 오브젝트의 피봇값으로
이동
-> 아이템이 숫자 앞에 놓인 것 처럼
만들어야 함
-> 아이템이 사용되었기 때문에
인벤토리에서 삭제

만들어야 함.
