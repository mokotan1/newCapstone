아트팀
전체적인 씬은 5개로구성되며 동서남북 책장과 데스크
가 있는 중앙 씬으로 귀결됨
중앙 씬에서는 컨셉 아트 처럼 중앙에 데스크가 있고 나
머지 길은 카펫으로 가야하는 길을 명시해둠
-> 플레이어로 하여금 여기로도 가야한다는 정보를 시각
적으로 주기 위함
데스크 위에는 일기장과 서재의 퍼즐인 암호문이 놓여져
있음.

아트팀(책장)
공통적으로 백스패이스가 들어가며 책장에는 여러가지
책이 있지만 퍼즐을 위해 빨간색, 파란색, 녹색의 책이 들
어가며 다른 색깔의 책은 전부 흰색 아니면 갈색으로 들
어갈 예정
책의 색깔은 추후 논의 후 업데이트 예정
-> 책장당 빨간색, 파란색, 녹색의 책들은 사칙연산을 했
을 때 0~9사이의수이며 음수나 10이상의 숫자가 될 수
없음.

개발팀(서재 중앙)
왼쪽 위의 백스패이스
-> 클릭되었을경우 메뉴를 띄우며
-> 나간다 클릭 == 복도 씬(HallWayRight2를로드)
-> 나가지 않는다 클릭 == 좀 더 둘러 본다는 대사 출력
예외 처리
-> 백스페이스를 클릭 하고 메뉴가 떴을 경우 다른 오브
젝트와의 상호작용은 false로유지
[EX]
백스페이스가 클릭 되었을 경우 데스크를 클릭 했을 때
데스크 패널이 뜨지 않도록 하는 것

<!-- page: 11 -->
개발팀(서재 중앙)
데스크 클릭
데스크를클릭 하였을 경우 메뉴창을뜨운다
-> 조사한다 or 비슷한 뉘양스의 대사
-> 조사한다를 클릭했을 경우 데스크 패널을 활성화
-> 데스크의 자식 오브젝트들 활성화 (패널의 백스페이
스나 데스크 패널 자식 오브젝트들)
예외 처리 : 백스페이스와 마찬가지로 패널을 활성화 했
을 경우 패널의 자식 오브젝트나 이미지가 아닌 이상 또
한 데스크를 활성화 했을 때의 퍼즐이나 일기장을 제외
한 다른 오브젝트들와의 상호작용은 false상태

개발팀(서재 중앙)
데스크 클릭 후 패널
패널을활성화 한 후 일기장과퍼즐로 사용할암호문의
자식 오브젝트들을 패널의 활성화와 같이 활성화
예외 처리 : 백스페이스와 마찬가지로 패널을 활성화 했
을 경우 패널의 자식 오브젝트나 이미지가 아닌 이상 또
한 데스크를 활성화 했을 때의 퍼즐이나 일기장을 제외
한 다른 오브젝트들와의 상호작용은 false상태상호 작용
이후 true 상태로 전환하여 상호작용 가능하도록

개발팀(책장)
책장은 퍼즐 풀이용 + 숨겨진 문을 활성화 하는데 쓰임
-> 책장 씬에 들어온 경우 책장의 방향을 오른쪽 위에 출
력 해준 뒤 책장을 클릭 하였을 경우 책장의 책 색깔 별
개수를 대사로 출력
-> 백 스페이스를 눌렀을 경우 복도로 나가는 경우 + 데
스크로 돌아가는 경우 2가지를 구현
-> 백 스페이스를 클릭하였을 경우 3가지선택지를 제공
1. 데스크로 돌아간다 => fade out + 중앙 서재 씬 로드
2. 복도로 돌아간다 => fade out + 복도 씬 로드
3. 그만둔다 => 그만둔다는 대사와 함께 책장 씬에 남음
