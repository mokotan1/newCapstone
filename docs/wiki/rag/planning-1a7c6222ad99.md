## Slide 11

개발팀(서재 중앙)

데스크 클릭

데스크를 클릭 하였을 경우 메뉴창을 뜨운다
-> 조사한다 or 비슷한 뉘양스의 대사

-> 데스크의 자식 오브젝트들 활성화 (패널의 백스페이스나 데스크 패널 자식 오브젝트들)

예외 처리 : 백스페이스와 마찬가지로 패널을 활성화 했을 경우 패널의 자식 오브젝트나 이미지가 아닌 이상 또한 데스크를 활성화 했을 때의 퍼즐이나 일기장을 제외한 다른 오브젝트들와의 상호작용은 false상태

## Slide 16

개발팀(책장)

책장은 퍼즐 풀이용 + 숨겨진 문을 활성화 하는데 쓰임

-> 책장 씬에 들어온 경우 책장의 방향을 오른쪽 위에 출력 해준 뒤 책장을 클릭 하였을 경우 책장의 책 색깔 별 개수를 대사로 출력

-> 백 스페이스를 눌렀을 경우 복도로 나가는 경우 + 데스크로 돌아가는 경우 2가지를 구현

-> 백 스페이스를 클릭하였을 경우 3가지 선택지를 제공

데스크로 돌아간다 => fade out + 중앙 서재 씬 로드
복도로 돌아간다 => fade out + 복도 씬 로드
그만둔다 => 그만둔다는 대사와 함께 책장 씬에 남음
