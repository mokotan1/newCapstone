필요 에셋
◆창문
-> 위 이미지 처럼 열쇠가 어디에 있는지 알려주기 위함
◆책상과 책장
-> 저택 주인이 어떤 교육을 중요시 여겼는지 보여주기
위한 장치
◆화이트 보드
-> 다음 퍼즐에 대한 힌트 및 앵무새가 내는 수수께끼에
대한 힌트를 주기 위함

• -> 빈 체크 박스 + 체크 된 체크 박스

<!-- page: 8 -->
필요 기능
◆창문
->클릭 시 패널 열림
-> 패널 이미지 = 위 창문 이미지 처럼
-> 대사 처리 = 임시로 “저기 열쇠가 있네” 정도
(다음 달에 대사 스크립트 뽑을 예정)
-> 백스페이스 필요
-> 창문을 눌렀을 경우 책상 위에 앵무새가 있
도록 함
◆책상과 책장
-> 대사 처리 =클릭 시 성경과 세계사에 대한 책이 올려
져 있다
-> if 창문을 클릭 했을 경우 책상에 대한 클릭 => false
+ 클릭 처리 앵무새에게들어가도록

<!-- page: 9 -->
필요 기능
◆화이트 보트
-> 성유물 3가지의 이름이 나옴
1. 엘레나의 성정
2. 보목
3. 성배
-> 이는 지금 자신이 모으고 있는 것이 성유물임을 밝히
기 위함
-> 성유물의 이름 뒤에는 네모 박스
-> 저 이름 중 하나의 이름을 가진 아이템이 인벤토리에
있으면 해당 아이템 이름의 네모 박스에 체크 표시가 있
는 네모박스(체크 리스트)
-> 스토리 진행의 길잡이를 위함
