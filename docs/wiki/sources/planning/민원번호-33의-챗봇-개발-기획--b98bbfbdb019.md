<!-- page: 2 -->
목차

- 문서의 목적 안내
• 시스템 설계
-메인 시스템인 ai 챗봇과 오브젝트의 상호작용

<!-- page: 3 -->
개요 (Overview)
• 문서의 목적
- 개발팀의 메인 시스템 설계에 있어 설계의 기준이 되기 위함
개발 엔진 : 유니티
대화 이벤트 시스템 : fungus
AI모델 : Open AI GPT API
주요 개발 언어 : C#

<!-- page: 4 -->
핵심 기능
동적 대화 생성
• 미리 작성된 대화가 아닌 ai와의 동적인 대화를 통해 Chat GPT
API를 실시간으로 호출하여 좀 더 NPC의 대화를 생성
• 유저의 예측 불허한 대답에 좀 더 유연하게 대처 가능한 NPC를
만드는 것이 가능

<!-- page: 5 -->
핵심 기능
상황 인지형 AI
NPC는 자신이 처한 상황과 장소에 따라 다른 말과 행동을 한다.
• 씬 별 스크립트 분리
각 장소 예를 들어 주방이나 매인 홀과 같은 장소에서 bool값 플
레그를 만들거나 유저가 어떠한 행동을 했을 경우 플래그를 만들
어 주고 그 플레그에 따라 ai의 프롬프팅 달리 하여 ai의 행동을
제한한다.

<!-- page: 6 -->
핵심 기능
상황 인지형 ai
• 외부 프롬프팅 파일 : 기본적인 ai의 페르소나, 역할, 지시사항들
을 텍스트 파일로 관리. 이로인해 코드의 수정 없이 ai의 성격이
나 ai에게 주는 지시사항 등을 자유롭게 변경 가능

<!-- page: 7 -->
핵심 기능
게임 이벤트 연동
• Fungus 변수 연동
Fungus 에서 선언한 글로벌 bool 변수를 c# 스크립트가 실시간으로
확인
-> true가 되면 api를 요청하기 전에 특별한 지시를 프롬프트에 삽입
[EX]
giveFood 라는 변수가 true가 되면 “카레에 대한 수수께끼를 내주세요”
라는 지시를 프롬프트에 삽입
-> ai가 노란색 향신료와 같은 수수께끼 같은 답변 생성

<!-- page: 8 -->
핵심 기능
플레이어와의 연동
• 플레이어의 직접 입력
inputField와 Button을 사용하여 플레이어가 AI에게 질문을 하거
나 대화를 함
[EX]
플레이어가 “안녕” 이라고 입력
->Ai는 나는 밤에 숨는자 와 같은 자신이 누구인지 수수께끼로
대답
