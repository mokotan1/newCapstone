선택 가이드

  • 세계관 몰입 중시 → ① 밀랍 인장 / ② 양피지 탭
  • 의미 직관성(기록·책) 중시 → ② 양피지 탭 / ⑤ 알약(아이콘+글자)
  • 대화창 안 가림·미니멀 중시 → ③ 고스트
  • 호러·무게감 중시 → ④ 음각 명판 / ① 인장
  • 현재 구조 호환: 현재는 77×77 정사각. ①·④는 정사각 그대로 교체 최소, ⑤는 가로 알약이라 슬롯 폭 조정 필요, ②는 clip-path 형태라 스프라이트(이미지) 권장

※ Unity 적용 시 rgba(0~255) → new Color(r/255, g/255, b/255, a). 글로우·베벨은 Shadow/Outline 컴포넌트 또는 스프라이트로 구현.
