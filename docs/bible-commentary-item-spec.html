서재 성경 해석본 아이템 스펙

책 홀더에서 집어 드는 닫힌 책 스프라이트와, 사용 시 펼쳐지는 주석서 패널을 한 흐름으로 정리한 시각 스펙이다. 첫 인상은 신학 서적, 사용 후 인상은 알프레드의 오독과 집착이 드러나는 오염된 단서책으로 잡는다.

Study Room / Bible Commentary

픽업 배치

책 홀더 위 닫힌 책

책상 클릭 후 패널에서 보이는 상호작용 오브젝트. 금박과 붉은 책갈피로 다른 문서와 구분한다.

스프라이트 상태안

기본, 호버, 획득 완료 상태를 같은 실루엣으로 유지한다. 실제 구현에서는 UI 하이라이트만 별도 레이어로 분리한다.

기본: 어두운 와인색 표지
호버: 얇은 금색 선택선
획득 후: 흐림 + 완료 표식

사용 시 패널

펼쳐진 성경 해석본

왼쪽은 정돈된 해석, 오른쪽은 알프레드의 밑줄과 붉은 잉크 메모를 배치한다. 단서는 읽기 흐름 안에서 자연스럽게 보이도록 밑줄 처리한다.

부활에 관한 주해

나사로의 부활은 죽음 이후의 소망을 상징한다. 본문은 죽음을 부정하는 기술이 아니라, 남겨진 이들에게 주어지는 위로로 읽힌다.

마리아와 마르타는 죽음 앞에서 기다림과 믿음을 보인 자매로 기록된다.

부활절은 해마다 날짜가 달라지며, 기록과 달력을 함께 대조해야 한다.

날짜 기록

2015년 부활절은 4월 5일이었다. 이 날은 죽음을 이기는 날로 기념되나, 사람의 손으로 죽음을 되돌리는 날은 아니다.

요한복음의 부활 구절은 믿음의 증언으로 남겨졌으며, 제물이나 실험의 근거가 될 수 없다.

죽음은 끝이 아니다.
올바른 절차와 충분한 믿음이 있다면 다시 부를 수 있다.

플레이 흐름

1. 서재 책상 조사

책상 패널에서 일기장, 암호문과 함께 성경 해석본이 보인다.

2. 해석본 획득

플레이어가 클릭하면 책 패널이 열리고 페이지 넘김 UI가 활성화된다.

3. 날짜 단서 저장

2015년, 부활절, 4월 5일을 기억하게 만든다. 직접 정답 표기는 피한다.

4. 안주인의 방 연결

달력, 부활 구절, 체셔의 “만월은 15일” 대사와 결합한다.

5. 비밀번호 도출

15 + 04 + 05 조합으로 150405를 입력해 서랍을 연다.

아트 및 구현 메모

아트 요구사항

닫힌 책은 작은 크기에서도 십자가, 금박, 붉은 책갈피가 읽혀야 한다.

픽업 크기권장 256x256 원본, Unity 내 96-128px 표시
패널 원본권장 1600x900 또는 UI 9-slice 가능한 분리 레이어
분리 레이어책 본체, 호버 선택선, 붉은 메모, 페이지 텍스트
금지현대적인 새 책 질감, 과도한 피 얼룩, 읽기 어려운 장식 글꼴

상호작용 규칙

책 패널이 열린 동안 서재 배경 오브젝트 입력은 막고, 책 내부 버튼만 받는다.

클릭 전책 홀더 위에서 선택 가능 표시
클릭 후“조사한다” 선택 후 펼친 책 패널 활성화
닫기백스페이스 또는 닫기 버튼으로 책상 패널 복귀
재열람퍼즐 전까지 반복 열람 가능, 획득 플래그와 열람 플래그 분리
