패널 안에서 사용할 백스페이스

PanelBackspaceCloser 용도

관리인의 기록

종이 탭처럼 패널 상단에 붙어 있어, 문서를 덮는 버튼이라는 느낌이 강합니다.

PANEL A

상단 종이 탭

책, 메모, 일지 패널에 가장 잘 맞습니다. 버튼이 패널에 소속되어 보이기 때문에 씬 이동 버튼과 혼동이 적습니다.

찢어진 요리책

붉은 봉인처럼 닫기 버튼을 처리해 공포 분위기와 상호작용성을 함께 강조합니다.

PANEL B

붉은 봉인 버튼

중요 단서나 긴장감 있는 오브젝트 패널에 좋습니다. 색이 강해서 발견성은 높지만, 반복 사용 시 조금 튈 수 있습니다.

채택

접힌 페이지

모서리가 접힌 듯한 처리로, UI 장식과 닫기 기능을 하나로 묶습니다.

PANEL C

접힌 모서리

가장 장식적인 안입니다. 공간을 적게 먹고 예쁘지만, 버튼이라는 인지가 약할 수 있어 hover/press 연출이 필요합니다.

챗봇 패널에서 사용할 백스페이스

대화창을 가리지 않는 닫기 버튼
AI

가정교사와 대화

버튼을 작게 우상단에 고정해 기존 창 닫기 문법을 그대로 사용합니다. 본문과 입력 영역을 거의 침범하지 않습니다.

CHAT A

미니 코너 닫기

가장 익숙한 챗봇 패널용 닫기입니다. 접힌 모서리안보다 덜 장식적이라 대화 UI에서는 안정적으로 읽힙니다.

AI

실마리 질문

상단 명패처럼 올려 버튼 목적을 텍스트로 분명히 보여줍니다. 처음 접하는 플레이어에게 가장 친절합니다.

CHAT B

상단 명패형

닫기인지 뒤로가기인지 혼동될 가능성이 가장 낮습니다. 대신 텍스트가 들어가서 분위기는 조금 UI답게 보입니다.

AI

대화 중단

왼쪽 위에 작은 뒤로가기 표식을 올려, 대화 흐름에서 한 단계 빠지는 느낌을 줍니다.

CHAT C

소프트 백 애로우

패널 닫기보다 대화 이전 단계로 돌아간다는 느낌이 강합니다. 챗봇에 하위 메뉴가 생길 경우 특히 잘 맞습니다.

다른 상호작용 패널에서 사용할 백스페이스

오브젝트 확대, 퍼즐, 조사 패널용
기본안

배전반 확대

패널 안 기본 채택안과 같은 접힌 모서리를 사용해 전체 상호작용 UI의 규칙을 통일합니다.

OBJECT A

접힌 모서리 공통형

사용자가 선택한 패널 3번을 일반 상호작용에도 그대로 확장한 안입니다. 책, 단서, 퍼즐 패널의 닫기 문법이 통일됩니다.

금고 조작

조작 영역을 가리지 않도록 오른쪽 가장자리에 손잡이처럼 붙이는 방식입니다.

OBJECT B

우측 사이드 탭

다이얼, 숫자판, 배전반처럼 중앙 조작이 많은 UI에 좋습니다. 손잡이처럼 보여 패널 바깥으로 빠지는 느낌도 있습니다.

사진 조사

하단 키처럼 분리해, 화면 위쪽 오브젝트나 힌트를 가리지 않습니다.

OBJECT C

하단 키 버튼

오브젝트를 크게 보여주는 조사 패널에 적합합니다. 기능은 명확하지만, 다른 채택안보다 게임 UI 느낌이 조금 강합니다.

씬 이동용 백스페이스

BackNavigator 용도
채택
SCENE A

좌상단 리본

가장 표준적인 내비게이션 형태입니다. 언제나 같은 위치에 둘 수 있어 학습 비용이 낮고, 패널 버튼과도 명확히 다릅니다.

SCENE B

하단 명패형

방에서 복도, 확대 화면에서 원래 공간으로 돌아가는 느낌을 텍스트로 직접 전달합니다. 모바일 터치 영역도 확보하기 쉽습니다.

SCENE C

좌측 세로 핸들

화면 가장자리에 붙은 물리적 손잡이처럼 보입니다. 몰입감은 좋지만, 처음 보는 플레이어에게는 기능 설명이 약할 수 있습니다.
